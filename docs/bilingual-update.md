# 中英文配音补齐

用户于 2026-11-17 明确要求：配音不能只有中文，必须同时提供中文和英文。既有全权执行和发布授权继续有效，无需重新确认设计。

实现方式：保留已发布中文成片，新增英文原声成片及对应英文画面、字幕、文字稿。网页选择“中文 / English”后，同步切换视频、字幕、章节、当前下载链接；按照相同分镜编号和段内比例映射播放位置，保留播放速度和播放状态。

步骤：
1. 添加不同长度分镜的播放时间映射回归及语言文件路径测试，先确认失败。
2. 将语音、渲染和媒体验证脚本改为显式 --lang zh/en；按同一25段动画和同一数值独立编写英文讲稿，生成冻结语音和成片。
3. 增加网页配音选择器与语言一致的资源链接；真实浏览器检查中英文切换、位置、倍速、字幕、章节和移动端。
4. 核验两版本音轨、音量、字幕、公开部署，保存源码和实际结果，更新定时任务。
