## 学习目标与内容结构

学生学完能够：从坐标手算 HPWL；列出 p 个 pin 的 p(p−1)/2 条 Clique 边且不重复；按指定现有 pin 作 Star 中心求和；说明中心依赖与对称反例；区分单 net 和全网、未加权和加权、测量值和布局合法性；用 Python 实现三个求值函数并对齐标准例。

页面采用连续的中文学习路线，同时提供锚点导航和“直接实验”。

1. **首屏**：标题“同一组引脚，为什么有三种线长？”；四个引脚的简洁图；开始学习/直接实验两个主入口。明确这是 Placement / Lesson 03，标注建议学习时间和前置。
2. **讲解视频**：可播放中英文两个独立配音 MP4，各自有同步字幕、文字稿和时间轴，并可在网页切换配音、章节跳转、倍速、下载和完整文字稿。视频尚未生成时不出现可点击的假下载按钮。
3. **三把尺子**：同一张 golden 图，依次解释 BBox、Clique、Star，显示公式、几何和真实求和；可前进、后退或自动演示。
4. **对比实验台**：三幅并排/移动端纵向 SVG 共享同一输入；选择引脚并拖动或使用坐标输入/方向键；选择 Star 中心；即时显示三个数、构成项、边数与输入坐标。默认 Golden，另有 Starter、非对称和内部点预设。
5. **反例与思考**：对称图上各 hub 恰巧相同；非对称时不同；内部 pin 移动时包围盒可能不变；重叠使值为零却不能证明布局合法；模型数值不能直接互相比小来排名“更好”。
6. **挑战与概念检查**：约 6 项实操挑战和 6 项概念题，提交后给出具体数值与原因。完成状态只由学生提交自己的答案触发，播放或载入预设不计完成。
7. **实现与资料**：可下载无依赖 Python 练习和独立参考实现、例子 JSON、文字稿。可选提供离线包；浏览器 Python、PPTX 和整站英文界面不是本轮必需项；中英文配音都必须完成。

## 算法与交互约定

三模型均使用二维曼哈顿距离，主实验只求 ABCD 的单 net、单位权重。BBox 为半周长；Clique 每对只计一次且无归一化；Star 中心必须是现有引脚。公式、标准坐标、全部期望值见课程范围文档，影片和实验不得各抄一套数字。

主实验不应用后续求解器中的 A/D fixed-pad 限制：这是测量模型，所有 pin 可编辑；界面明示。坐标原点左下、y 向上，初始支持整数 0–8。内部计算不依赖 SVG 屏幕像素；拖动吸附整数网格。坐标表、方向键和拖动等价。重置返回当前预设初始状态，不删除答题记录；另设清除学习记录按钮。自由实验限于四引脚，不做任意 JSON 编辑器以免扩大范围。

引擎为无 DOM 的纯函数，返回数值及逐项 trace；网页与动画导出都使用可核对的同一数据。Python 参考应独立实现公式，不通过调用 JavaScript 再把输出当作独立验证。无效输入（非有限值、缺失 pin、重复 pin、非法 hub）明确拒绝；0/1 pin 的通用函数返回 0，空 net 的约定在代码文档中固定。全网权重仅作为解释资料，不混入主实验。

实操挑战建议：手算 golden；列全六条 Clique 边；比较非对称四个 hub；在包围盒不变时改变另两指标；识别双计数；发现重叠零线长的局限。数值题使用容差，不用不稳定浮点字符串判等。题目允许重试，展开答案有明显提示，不偷改成绩。

## 视觉与动画

网站阅读区以温暖浅底、深蓝绿文字、细线与充分留白为主；视频和实验图使用用户指定的深蓝绿底，青绿/暖金/灰蓝作三模型区分。三模型同时有文字标签和不同线型，不能只靠颜色。

视频的精确参考色值见 `docs/research/video-reference.md`。新片建议 4–6 分钟、1080p、30 fps；图形连续缓动并与实际坐标重算同步，逐条画线、累计数字、保留短暂停顿让观众理解。避免在一帧中塞满公式。动画对象与字幕区域分开，字幕每屏不超过两行主要中文。

旁白分别提供合成普通话和英文原声，每句先生成真实音频，再按实际时长排分镜；缓存音频防止每次重渲染重新调用服务。语音引擎选择交由实现者，根据环境优先选可用且无需额外付费的高质量中文与英文声音。若可用方案只有音质明显不足的系统声音，先生成短样片并如实标注，不能用字幕或浏览器朗读冒充成片配音。

视频以“一个 net 连接多个 pin”为起点，用 golden 4/16/8 建立三模型，再用非对称 11/36/Star 16,22,14,20 展示 hub 影响，最后进入实验。网格与边数帮助理解，所有几何连线均标注为模型示意而非真实布线路径。
