# Lesson 03 Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task. User chose full execution without intermediate design approvals.

**Goal:** Publish a complete Chinese net-models lesson with verified experiments and a narrated animated MP4.

**Architecture:** Buildless HTML/CSS/ES modules and SVG; a pure model engine supplies traces and shared presets. Independent Python validates the engine and renders a deterministic film using the same exported data; cached Chinese speech determines scene timings.

**Tech Stack:** Node test runner, Python/Pillow/NumPy, FFmpeg, Mandarin TTS, GitHub Pages.

**Spec:** `docs/course-design.md`

## Global Constraints

- Golden single net: HPWL 4, Clique 16, Star-from-A 8. Unit Manhattan distances, existing-pin hub.
- All four pins editable, integer coordinates 0–8; pointer and keyboard equivalence.
- 1080p/30fps MP4, real Mandarin audio, VTT, transcript, reproducible source; no background music required.
- GitHub Pages project subpath, local assets, responsive layout and reduced motion.
- Preserve attribution and actual verification limits; user already authorized push and publication.

## Review Focus

- Invalid/empty coordinates never silently become zero; validate before updating state.
- Pointer cancellation and keyboard input must leave experiments usable and synchronized.
- Storage unavailable must not block learning; presets never count as independent challenge completion.
- Media and captions must exist and resolve under the project subpath.
- Film numbers must follow the displayed geometry and voice timing, including moving pins.
