# 视频配色与制作要求

用户明确要求参考 Partitioning_Module_Coordinator 门户视频的**配色**，并制作本课的流畅动画与语音讲解。

已实际查看本地参考封面 `Partitioning_Module_Coordinator/site/media/home/intro.zh.jpg`，读取 `video/home/storyboard.json`、`scripts/film/graphics.py` 以及 `render_intro.py`。远端参考分支 course-upgrades 当前 SHA：`c9a3f8934261c0a96d713cbec5acad0262e279e7`。本地文件版本与该 SHA 不应未经比对即宣称完全一致。

参考的特点是深色留白、细网格、米白标题、青绿信息标签与暖金色数学强调，不需要复制原片的情节或配乐。

新片建议 4–6 分钟、1920×1080、30 fps、H.264/AAC MP4。围绕同一四引脚实例，顺序讲多引脚问题→BBox→Clique→Star→非对称反例→改变坐标→模型边界→实验邀请。坐标点沿连续轨迹缓动，包围盒追随当前插值后的坐标，边逐条出现，求和同步；不能以静态幻灯片加转场代替主要教学动画。

必须有真实音频轨中的中文合成旁白，不能仅调用浏览器临时朗读。旁白分句生成、缓存，按实际音频时长排分镜。字幕提供 VTT 与文字稿；下载后无网络也能听。旁白优先于音乐，可不配音乐。

验收：音轨存在且非静音、普通话可懂且读法自然；字幕、图中公式和旁白一致；章节可定位；抽查开头、中段和结尾；提供可复现分镜与渲染源码。不得在没有试听或转写核验时宣称已经完成听感验收。
