参考实现：逐项核对结果

这是独立于网页 JavaScript 引擎的 Python 实现。先完成练习，再对照坐标扫描、无序对求和与中心选择。

PYTHON / reference.py
"""Independent Manhattan net model reference. Python 3.9+, standard library only.
Run: python3 reference.py < inputs.json
inputs.json: list of nets, each net = [{"id":"A","x":2,"y":2}, ...]
Outputs [bbox, clique, star-from-first-pin] for each net.
"""
import json,sys,math,itertools
def evaluate(pins,hub=None):
    ids=[p['id'] for p in pins]
    if len(ids)!=len(set(ids)): raise ValueError('Duplicate pin')
    for p in pins:
        if any(isinstance(p[k],bool) or not isinstance(p[k],(int,float)) or not math.isfinite(p[k]) for k in ('x','y')): raise ValueError('Invalid coordinate')
    if not pins:return [0,0,0]
    hub=ids[0] if hub is None else hub
    if hub not in ids:raise ValueError('Invalid hub')
    distance=lambda a,b:abs(a['x']-b['x'])+abs(a['y']-b['y'])
    bbox=sum(max(p[k] for p in pins)-min(p[k] for p in pins) for k in ('x','y'))
    clique=sum(distance(a,b) for a,b in itertools.combinations(pins,2))
    h=next(p for p in pins if p['id']==hub)
    return [bbox,clique,sum(distance(h,p) for p in pins)]
if __name__=='__main__':print(json.dumps([evaluate(p) for p in json.load(sys.stdin)]))

完整中文讲义

同一组引脚，三把不同的尺子

Placement · Lesson 03 · FanqinZeng

目标和约定

学会从坐标求 BBox/HPWL、Clique 和 Star，说明每一项来自哪里，识别三种模型的限制。本课使用单个 net 的单位权重、二维曼哈顿距离。四个引脚均可移动，这是测量实验，不是带固定单元约束的布局优化器。

坐标原点在左下，y 向上。两引脚之间的曼哈顿距离为 |xᵢ−xⱼ|+|yᵢ−yⱼ|。图中的折线表示这个距离，不能当成实际共享布线。

三个模型

  1. BBox / HPWL：找到 x、y 各自的最大和最小值，结果为 (max x−min x)+(max y−min y)。它是包围盒半周长，不是完整周长。扫描 p 个引脚一次，时间 O(p)。
  2. Clique：对所有无序引脚对 i<j，分别求曼哈顿距离再相加。共有 p(p−1)/2 对，时间 O(p²)。本课未归一化，也没有使用距离平方。
  3. Star-from-h：选一个现有引脚 h 为中心，只求它到其余 p−1 个引脚的距离总和。时间 O(p)。h 的选择属于定义；虚拟中心是另一个约定。

可以手算的标准例

Pinxy
A22
B42
C24
D44

HPWL = 2+2 = 4。

Clique 的六对为 AB=2、AC=2、AD=4、BC=4、BD=2、CD=2，总和 16。AB 和 BA 不能各算一次。

Star-from-A = AB+AC+AD = 2+2+4 = 8。

三个反例

中心依赖。 A(0,0)、B(6,0)、C(1,2)、D(2,5)，HPWL=11、Clique=36。Star 的中心依次选 A/B/C/D，得到 16/22/14/20。因此对称正方形四个中心恰好同值，不能推出一般情况换中心不变。

内部点的盲区。 A(0,0)、B(8,0)、C(0,8)、D(4,4)。把 D 改成 (2,2)，HPWL 仍是 16，Clique 从 56 降到 52，Star-from-A 从 24 降到 20。边界没有变，不意味着其他模型没有变化。

零值不是合法性证书。 所有点重叠，三个值都为零。模型没有检查真实单元的面积、重叠、密度与时序，所以不能据此宣布布局完成。

比较需要同一口径

同图的 4、16、8 测的是不同对象，不能凭数字大小判定哪个模型“最好”。比较两个布局候选时，先对齐模型、距离、权重和约束。HPWL 是估计，不是精确实际布线长度。

本课主实验只测 ABCD。教师六个 net 的未加权总 HPWL 为 52→14；加入 [1,1,1,1,5,1] 权重后为 116→30。不要把全网数值和单 net 的 16→4 放在同一列混用。

实现与验证

完成 exercise.py 的三个函数，再用 reference.py 核对。输入为列表，每个 pin 有 id、x、y；名字不能重复，坐标必须是有限数。空或单 pin net 的结果为零；有 pin 时 hub 必须属于输入。两个 pin 时三模型数值相同。

检查平移不变性、统一正比例缩放，以及所有现有引脚作中心的 Star 总和等于两倍 Clique。程序还应拒绝缺失坐标、NaN、重复名字和非法中心。

One set of pins, three different rulers

Placement · Lesson 03 · FanqinZeng

Goals and conventions

Compute BBox/HPWL, Clique, and Star from coordinates, explain every contribution, and recognize the limitations of each model. We use a single net with unit weights and two-dimensional Manhattan distance. All four pins can move: this is a measurement experiment, rather than a placement optimizer with fixed-cell constraints.

The origin is at bottom left, with y pointing up. The Manhattan distance between two pins is |xᵢ−xⱼ|+|yᵢ−yⱼ|. The bent lines illustrate this distance; they are not actual shared routing.

Three models

  1. BBox / HPWL: find the minimum and maximum coordinates on each axis. The result is (max x−min x)+(max y−min y). This is the bounding box’s half-perimeter, rather than its full perimeter. A single scan of p pins takes O(p) time.
  2. Clique: sum the Manhattan distance of every unordered pair i<j. There are p(p−1)/2 pairs, giving O(p²) time. This lesson uses neither normalization nor squared distances.
  3. Star-from-h: choose an existing pin h as the hub and sum its distances to the other p−1 pins. This takes O(p) time. The choice of h is part of the definition; a virtual hub is a separate convention.

A standard example you can calculate by hand

Pinxy
A22
B42
C24
D44

HPWL = 2+2 = 4.

The six Clique pairs are AB=2, AC=2, AD=4, BC=4, BD=2, and CD=2, for a total of 16. Count AB and BA as one pair.

Star-from-A = AB+AC+AD = 2+2+4 = 8.

Three counterexamples

Hub dependence. For A(0,0), B(6,0), C(1,2), and D(2,5), HPWL=11 and Clique=36. Using hubs A/B/C/D gives Star values of 16/22/14/20. The four equal hub values in the symmetric square do not imply that changing hubs preserves the value for every input.

The interior blind spot. Start with A(0,0), B(8,0), C(0,8), and D(4,4). Move D to (2,2). HPWL stays at 16, while Clique drops from 56 to 52 and Star-from-A from 24 to 20. An unchanged boundary does not imply unchanged values in the other models.

Zero is not a legality certificate. If all pins overlap, all three values are zero. These models do not check physical cell area, overlap, density, or timing, so the result does not certify a completed placement.

Compare like with like

The values 4, 16, and 8 measure different quantities on the same diagram. Their relative sizes cannot tell us which model is “best.” Before comparing two candidate placements, align the model, distance metric, weights, and constraints. HPWL is an estimate, rather than exact routed wirelength.

The main experiment measures only ABCD. Across the teacher’s six nets, total unweighted HPWL changes 52→14; with weights [1,1,1,1,5,1], it changes 116→30. Do not mix these all-net values with single-net ABCD’s 16→4 in the same comparison column.

Implementation and verification

Complete the three functions in exercise.py, then compare with reference.py. Input is a list of pins, each with id, x, and y. IDs must be unique and coordinates finite. Empty or single-pin nets give zero; for a nonempty net the hub must be present. With two pins, all three models agree.

Check translation invariance and uniform positive scaling. Also check that the sum of Star values over every existing pin as hub equals twice the Clique value. Reject missing coordinates, NaN, duplicate IDs, and invalid hubs.

第一种模型，先找到所有引脚的最小包围盒。最左、最右确定宽，最下、最上确定高。半周长线长，就是宽加高。

00:01:30.900 · 一次扫描，就能算完

无论有多少引脚，包围盒只需要四个极值。扫描每个引脚一次，就能得到结果。所以它计算便宜，适合快速估计网络的线长。

00:01:44.533 · 第二把尺子：每一对都量

第二种模型叫完全图模型，也叫克利克模型。它把每对不同引脚都连起来。四个引脚共有六对，同一对只计算一次。

00:01:56.800 · 每一项，都有对应的引脚对

按字母顺序，先算 A 到 B、A 到 C、A 到 D，再算 B 到 C、B 到 D，最后算 C 到 D。六个距离依次是二、二、四、四、二、二。

第三种是星形模型。先选一个现有引脚作中心，再把它连到其他引脚。本课把 A 作为中心，没有额外加入虚拟节点。

现在，同一组点得到了四、十六、八。连接没有改变，坐标也没有改变，只是求和方式不同。这些数不能直接用来给模型排优劣。

标准正方形里，四个角作星形中心，结果恰好一样。这个现象来自对称性。换成一张不对称的图，我们就能看见中心的影响。

One net. Three rulers.

Voice: en-US-JennyNeural; duration 349.77 s.

00:00:00.000 · One net. Three rulers.

How can the same set of pins have three different wirelengths? In this lesson, we use three different rulers to understand net models in chip placement.

00:00:10.467 · Connections first. Positions next.

A net on a chip can connect several pins at once. The connections are already specified; placement chooses their positions. Before estimating wirelength, we must also choose a measurement model.

00:00:24.767 · Four pins we can check by hand

Start with four pins at the corners of a square of side two. We use these same coordinates throughout, comparing a bounding box, a clique, and a star.

00:00:35.733 · Horizontal plus vertical

We use Manhattan distance, rather than straight-line distance. Add the absolute horizontal difference to the absolute vertical difference. The bent lines in our drawings illustrate that measurement.

00:00:49.533 · From A to D: two plus two

From A at the lower left to D at the upper right, move two units horizontally and two vertically. Their Manhattan distance is four. Every model here uses this same basic distance.

00:01:02.833 · Ruler one: measure the boundary

The first model finds the smallest box containing all pins. The leftmost and rightmost pins determine its width. The lowest and highest determine its height. Add width and height.

00:01:17.067 · Half the perimeter, not all of it

For our square, width and height are both two, giving a half-perimeter wirelength of four. Walking around all four sides gives eight. That is the full perimeter, not this metric.

00:01:30.967 · A single scan is enough

The bounding box needs only four extreme coordinates. Scan each pin once to find them, so the computation grows linearly with the number of pins. It is a cheap wirelength estimate.

00:01:44.433 · Ruler two: measure every pair

The second model is a clique: connect every pair of distinct pins and add their Manhattan distances. Four pins give six unordered pairs. Count each pair exactly once.

00:01:57.967 · Every term names a pair

In alphabetical order, measure A to B, A to C, and A to D; then B to C, B to D, and C to D. The six distances are two, two, four, four, two, and two.

00:02:13.067 · Six distances add up to sixteen

Adding these six terms gives sixteen. Do not count both A to B and B to A. Those names describe the same unordered pair; double counting would incorrectly produce thirty-two.

00:02:26.200 · The edge count grows quadratically

With p pins, a clique has p times p minus one, divided by two edges. Here we sum unnormalized Manhattan distances. This is not the squared-distance objective used in quadratic placement.

00:02:40.767 · Ruler three: choose a hub

The third model is a star. Choose one existing pin as a hub and connect it to every other pin. Our example uses A. We do not introduce a virtual center.

00:02:53.867 · Measure only three spokes

With A as the hub, the spokes are A to B, A to C, and A to D. Their lengths are two, two, and four, totaling eight. Other pin pairs do not enter this sum.

00:03:07.500 · The hub is part of the definition

A star has only p minus one spokes, so its computation is linear in the pin count. But the hub is part of the model definition. Always name it when reporting the result.

00:03:20.367 · Same pins. Three readings.

The same pins now give four, sixteen, and eight. Neither their coordinates nor their connections changed. Only the measurement changed. These numbers alone cannot rank which model is better.

00:03:35.267 · Break the symmetry

For the square, choosing any corner as the star hub happens to give the same answer. That is a consequence of symmetry. An asymmetric example reveals why the hub matters.

00:03:48.200 · Change the hub. Change the result.

Using A, B, C, and D as hubs now gives sixteen, twenty-two, fourteen, and twenty. C has the smallest value here. This shows hub dependence; it does not prove a placement algorithm is optimal.

00:04:04.267 · An interior move can stay hidden

Next, A, B, and C support an eight by eight bounding box. Move the interior pin D from four, four to two, two. Watch the three rulers: which readings change?

00:04:18.767 · One move. Different sensitivities.

The half-perimeter stays sixteen because the outer boundaries did not change. The clique decreases from fifty-six to fifty-two, and the star from twenty-four to twenty. Different models respond differently to the same move.

00:04:33.867 · Zero wirelength is not a legal layout

Place every pin at one position and all three wirelengths become zero. Real cells have area and cannot freely overlap. These measurements have not checked density, overlap, or timing.

00:04:47.933 · A model drawing is not routed wire

The bent lines illustrate measurement relationships, not final shared routing paths. Before comparing two placement candidates, align the model, the distance, the weights, and the constraints. Small numbers need a clear definition.
